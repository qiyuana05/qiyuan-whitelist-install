## 2. 安装验证细节

### 2.1 普通自签

```bash
apksigner sign --ks normal.p12 ... --out app-normal.apk aligned.apk
adb install -r app-normal.apk
```

结果：

```
Failure [INSTALL_FAILED_VERIFICATION_FAILURE]
```

或界面提示"应用未安装"。

### 2.2 目标序列号自签

```bash
openssl x509 -req -in csr.csr -signkey private.key \
  -out certificate.crt -days 3650 -set_serial 0x<TARGET_SERIAL>
# ... 打包 p12、对齐、签名
adb install -r app-signed.apk
```

结果：`Success`。

### 2.3 覆盖安装

在已有同包名、不同签名版本的情况下：

```
Failure [INSTALL_FAILED_UPDATE_INCOMPATIBLE]
```

原因：PackageManager 要求覆盖时签名一致。解决方式见
[05-风险与恢复](05-风险与恢复.md)。

## 3. 卸载验证细节

### 3.1 设置界面

- 签名 = 系统证书的应用：设置 → 应用管理里**没有卸载按钮**；
- 包名在白名单且签名不匹配：可以卸载；
- 包名不在白名单且签名不匹配：通常也卸不掉（取决于系统版本）。

### 3.2 `pm uninstall`

```bash
adb shell pm uninstall <pkg>
```

签名匹配系统时的输出：

```
Failure [<pkg> is auth app, not allow delete!]
```

logcat 关键字：

```
VecentekPMS
Test delect-------------------
WhiteListHelper
CertificateM
```

### 3.3 结论

- 卸载拦截发生在 `PackageManagerService.deletePackageVersioned()`；
- 先查白名单；不在名单里，再看是否"签名等于 Settings"；
- 是 → 返回 `-7`，删除不发生；
- 不是 → 继续正常删除流程。

## 4. 平台差异

| 平台 | 序列号 | 说明 |
|---|---|---|
| 本车（长安 AIS） | `<TARGET_SERIAL>` | 2026-08 提取 |
| 梧桐车联 WTCL（其他车型） | `<OTHER_PLATFORM_SERIAL>` | 网上教程常见，**不能照抄** |
| 其他年款/OTA | 可能变化 | 每次 OTA 后应重新提取 |

结论：**序列号是平台/版本相关的，必须从自己的车机上取。**
